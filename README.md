# LuminaDB Releases

This repository hosts public release binaries (macOS DMG, Windows installer,
Linux `.deb`) for [LuminaDB](https://github.com/akshayrastogi-md/lumina-db), a
desktop client for SQL and NoSQL databases.

Source code is maintained in a private repository. This repo exists only so
package managers (APT, AUR, Snap Store, Flathub) and end users have a stable
public URL to download built artifacts from.

## Install

See the [Releases](../../releases) page for the latest downloads.
